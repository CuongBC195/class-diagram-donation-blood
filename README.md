### Cách 2: Kéo thả file vào Draw.io Web
1. Tải bất kỳ file `.drawio` nào từ repository này về máy.
2. Truy cập [app.diagrams.net](https://app.diagrams.net).
3. Kéo thả file vừa tải vào trang web để xem trực quan đầy đủ các tab.

---

### Cách 3: Xem và chỉnh sửa trực tiếp trong VS Code
Nếu clone repo về máy và dùng VS Code:
1. Cài Extension: **Draw.io Integration** (tác giả *Henning Dieterichs*).
2. Nhấp chuột vào bất kỳ file `.drawio` nào để xem sơ đồ trực quan và chuyển tab tương tác.
